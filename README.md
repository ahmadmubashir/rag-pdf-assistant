# rag-pdf-assistant
RAG-based PDF chatbot using Sentence Transformers, FAISS vector search, and TinyLlama for local AI question answering.
# 📄 Chat With Your PDF (RAG Chatbot)

This project is a Retrieval-Augmented Generation (RAG) chatbot that allows users to query PDF documents using AI.

---

## 🚀 Features

- Upload PDF files
- Extract text with page + line tracking
- Semantic search using FAISS
- Sentence embeddings (MiniLM)
- AI-powered answers using TinyLlama
- Streamlit interactive UI

---

## 🧠 Tech Stack

- Streamlit
- Sentence Transformers
- FAISS (vector search)
- TinyLlama (LLM)
- PyPDF
